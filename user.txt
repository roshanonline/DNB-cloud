========================================================================
 RESETTING UNKNOWN / [UNVERIFIED] PASSWORDS
========================================================================
 Run from the backend/ folder to force every account to a known value:

   ../.venv/Scripts/python.exe manage.py shell

 then paste:

   from apps.accounts.models import User
   for u in User.objects.all():
       pw = 'admin123' if u.role == 'ADMIN' else \
            (u.department or 'DEPT') + '123' if u.role == 'DEPARTMENT' else \
            'student123'
       u.set_password(pw); u.initial_password = pw; u.save()

 Staff portal reset:

   from apps.staff.models import StaffUser
   from django.contrib.auth.hashers import make_password
   StaffUser.objects.filter(staff_id='STAFF-CSE-2026-001').update(
       password=make_password('kar@123'))
